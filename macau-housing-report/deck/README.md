# 簡報生成器（v2，40 頁）

`deck.js` 生成 `澳門房屋問題-小組研習報告.pptx`（40 頁，每頁附講者備註）。
v1（51–53 頁）的生成器仍在 git 歷史中（commit `5073722` 至 `36aa514`）。

結構：引言（2–4）→ 概念（5–7）→ 問題一（8–13）→ 問題二（14–18）→ 問題三（19–24）→
社會因素（25–27）→ 馬克思理論三透鏡（28–31）→ 措施（32–34）→ 總結（35–37）→ 附錄（38–40）。
45 分鐘時間分配：開場 3、概念 4、問題一 8、問題二 6、問題三 8、社會因素 3、理論 6、措施 4、總結 2、答問 1。

「訪問引用位」（虛線框）在第 12、17、20、32 頁，匯報前要填入受訪者原話；第 38 頁交代受訪者。

設計語言沿用組員提供的 Canva 模板：奶白 `EEEBE3` 配純紅 `CA0013`、
巨型標題配極緊行距、細紅線作列表分隔、相片出血到版邊、括號頁碼。
中文字體用微軟正黑體，數字與拉丁字用 Inter（與模板一致，Canva 內建）。

## 重新生成

```bash
npm install pptxgenjs
node deck.js
```

## 檢查

本沙箱的 LibreOffice 載不到 pptx，所以改用兩個腳本：

1. `audit.py` —— 以 python-pptx 讀出每個形狀的實際框界，按中文全寬 1.0em、拉丁 0.52em 估算行數與所需高度，
   檢查文字溢出、出界、文字互相疊壓、文字壓在相片／圖表上、內容越入頁碼區，以及講者備註是否缺失。
   封面的樓房疊標題與封面頁腳屬刻意設計，會被列出，其餘應為零。
2. `render.py` —— 以 pymupdf 近似渲染成 PNG（逐字排版，含簡單長條圖與折線圖）供目視檢查。
   斷行為估算，與 PowerPoint 實際斷行略有出入，只用於確認版式。

```bash
python3 audit.py 澳門房屋問題-小組研習報告.pptx
python3 render.py 澳門房屋問題-小組研習報告.pptx out 1,14,22,35   # 指定頁碼；不填則全部
```
